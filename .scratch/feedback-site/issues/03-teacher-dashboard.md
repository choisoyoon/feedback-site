# 03: 선생님이 반을 고르면 수업별 제출 현황과 아직 피드백하지 않은 글이 보인다

**만들 것:** 선생님 화면 맨 위에서 [전체 | 반별] 버튼으로 반을 고르면, 그 반 기준으로 "수업별 제출 현황" 표, "아직 피드백하지 않은 글" 목록, 이름 없는 "어려웠던 점 모아 보기"가 보입니다. 학생 이름을 누르면 그 학생의 글이 열리고, [숫자 초기화]로 숫자를 잊은 학생을 도울 수 있습니다. (PRD 핵심 장면 2)

> 바뀐 결정(10/8): "차시 고르기 + 요약 숫자 + 학생별 목록"을 반별 "수업별 제출 현황"과 "아직 피드백하지 않은 글"로 바꿨습니다. 앞의 세 화면 영역(반 버튼, 제출 현황 표, 아직 피드백하지 않은 글, 어려웠던 점 모아 보기)은 01 작업 때 먼저 만들어 두었습니다. 02에서 학생 글이 저장되기 시작하면 숫자가 채워집니다.

**먼저 끝나야 할 티켓:** 02 (학생이 글을 내면 숫자 안내가 보인다)

**Status:** ready-for-agent

- [ ] 선생님 화면 맨 위에 [전체]와 선생님이 넣은 반 이름 버튼이 보이고, 누른 버튼이 색으로 표시된다.
- [ ] "수업별 제출 현황" 표에 차시마다 한 줄씩, 최근 차시가 위에 보인다. 칸은 제출, 아직, 피드백 보냄, 읽음, 답글이다.
- [ ] 반 버튼을 바꾸면 표의 숫자가 그 반 기준으로 바뀐다.
- [ ] 인원수를 넣은 반은 제출이 `N / M명`, 아직이 `K명`으로 보인다. [전체]에서는 모든 반에 인원수가 있을 때 인원수가 더해져 보이고, 아니면 제출 수만 보이고 아직은 `-`로 보인다.
- [ ] "아직 피드백하지 않은 글"에 피드백을 보내지 않은 글만 `차시 · 반 번호 이름 · 낸 시각`으로 보이고, 반 안에서 번호순이다.
- [ ] 피드백을 보낸 글은 "아직 피드백하지 않은 글"에서 사라진다.
- [ ] "어려웠던 점 모아 보기"에 차시별로 이름 없이 문장만 보이고, 비워서 낸 칸은 나오지 않는다.
- [ ] 순위나 점수는 어디에도 보이지 않고, 아직 내지 않은 학생의 이름도 보이지 않는다.
- [ ] 학생 이름을 누르면 그 학생의 글과 어려웠던 점이 보인다.
- [ ] [숫자 초기화]를 누른 뒤 그 학생으로 들어가면 새 숫자를 정하는 칸이 보이고, 새 숫자로 들어가면 예전 글이 그대로 보인다.
