# 01: 선생님이 반과 과제를 준비한다

**만들 것:** 첫 화면에 학생 들어가기 창(반, 번호, 이름, 숫자 4자리)이 바로 보이고, 화면 맨 위에 [처음으로]와 [선생님 화면] 버튼이 늘 보입니다. 학생 창은 이 티켓에서는 모양과 입력 확인까지만 만들고, 실제로 들어가는 기능은 02에서 만듭니다. 선생님은 처음 들어올 때 비밀번호를 정하고, 다음부터는 그 비밀번호로 들어옵니다. 선생님 화면에서 반 이름과 인원수를 넣고, 과제(제목, 질문 최대 3개, 참고 링크)를 올립니다. 이 티켓이 끝나면 학생이 고를 반과 과제가 생깁니다.

**먼저 끝나야 할 티켓:** 없음 (바로 시작)

**Status:** ready-for-agent

- [ ] 화면 맨 위에 [처음으로]와 [선생님 화면] 버튼이 어느 화면에서나 보인다.
- [ ] 첫 화면에 반(고르기), 번호, 이름, 숫자 4자리 칸과 "글에는 민감한 개인 정보를 적지 마세요" 안내가 보인다.
- [ ] 반 목록에는 선생님이 넣은 반이 보인다. 반이 없으면 "선생님이 아직 반을 만들지 않았어요"가 보인다.
- [ ] 칸을 비우거나, 번호에 숫자가 아닌 것을 넣거나, 숫자 4자리가 아니면 안내 문구가 보이고 넘어가지 않는다.
- [ ] 선생님 화면을 처음 열면 비밀번호를 정하는 칸이 보인다.
- [ ] 비밀번호를 정한 뒤 [처음으로]를 누르고 다시 [선생님 화면]을 누르면 비밀번호를 묻는다. 틀리면 열리지 않고, 맞으면 열린다.
- [ ] 반 이름과 인원수를 넣으면 반 목록에 나타난다.
- [ ] 과제 제목, 질문 1~3개, 참고 링크(비워도 됨)를 넣으면 과제 목록에 나타나고, 최근 차시가 위에 보인다.
- [ ] 질문 칸은 3개보다 더 늘릴 수 없다.
- [ ] 새로 고침해도 비밀번호, 반 목록, 과제 목록이 남아 있다.
