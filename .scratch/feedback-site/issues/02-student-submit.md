# 02: 학생이 글을 내면 숫자 안내가 보인다

**만들 것:** 학생은 01에서 만든 들어가기 창에 반, 번호, 이름(실명), 숫자 4자리를 넣고 들어옵니다. 차시별 과제 목록에서 과제를 열고, "이해한 내용"과 "어려웠던 점"을 써서 냅니다. 처음 내면 숫자 안내가 크게 보입니다. 피드백이 오기 전까지는 글을 고칠 수 있습니다. 다른 학생의 글은 보이지 않습니다. (PRD 핵심 장면 1)

**먼저 끝나야 할 티켓:** 01 (선생님이 반과 과제를 준비한다)

**Status:** ready-for-agent

- [ ] 처음 쓰는 반·번호면 이름과 숫자 4자리를 정하고 들어가, 차시별 과제 목록이 최근 차시부터 보인다.
- [ ] 과제를 열면 제목, 질문, 참고 링크, "이해한 내용"과 "어려웠던 점" 칸이 보인다.
- [ ] "이해한 내용"이 비어 있으면 제출되지 않는다. "어려웠던 점"은 비워도 제출된다.
- [ ] 처음 제출하면 "당신의 숫자는 ○○○○입니다. 적어 두세요"가 크게 보인다.
- [ ] 과제 목록에서 제출한 과제에 "제출 ✓"가 보인다.
- [ ] 같은 반·번호로 이름이나 숫자를 틀리게 넣으면 "숫자가 맞지 않아요. 잊었으면 선생님께 말해 주세요"가 보이고 들어가지지 않는다.
- [ ] 제출한 과제를 다시 열면 [고치기] 버튼이 보이고, 고친 내용이 다시 열어도 남아 있다.
- [ ] 다른 번호로 들어가면 앞 학생의 글이 보이지 않는다.
- [ ] 새로 고침해도 낸 글이 남아 있다.
