# 05: 학생이 피드백을 읽고 반응하면 선생님 목록에 보인다

**만들 것:** 학생이 피드백을 열면 읽은 시각이 남고 🔔가 사라집니다. 학생은 이모지(👍 😊 🤔) 하나와 답글 한 줄을 남길 수 있습니다. 선생님 학생별 목록과 요약에 읽은 시각, 반응, 답글이 보입니다. (PRD 핵심 장면 4)

**먼저 끝나야 할 티켓:** 04 (선생님이 피드백을 보내면 학생 화면에 🔔가 보인다)

**Status:** ready-for-agent

- [ ] 학생이 피드백이 온 과제를 열면 "잘한 점"과 "다음 걸음"이 보이고, 과제 목록의 🔔가 사라진다.
- [ ] 선생님 학생별 목록에 읽은 시각이 보이고, 학생이 다시 열어도 처음 시각 그대로다.
- [ ] 학생이 이모지를 누르면 고른 것이 표시되고, 다른 이모지를 누르면 바뀐다.
- [ ] 학생이 답글 한 줄을 보내면 학생 화면에 답글이 보이고, 다시 쓰는 칸은 사라진다.
- [ ] 선생님 학생별 목록에 이모지와 답글이 보인다.
- [ ] 선생님 요약의 "읽음 수"와 "답글 수"가 늘어난다.
